Variables y la función print()

Una variable es como una cajita con nombre donde guardas algo. En Python se crea así:

nombre = "Sofía"

Estamos diciendo: "crea una cajita llamada nombre y guarda dentro la palabra Sofía". Las comillas son obligatorias cuando guardas texto (los programadores le dicen "string").

Para mostrar en pantalla lo que hay dentro de una variable, usas print():

print(nombre) # Resultado: Sofía

Importantísimo: cuando pones la variable sin comillas, Python muestra lo que hay adentro de la cajita. Si la pusieras entre comillas (print("nombre")), mostraría literalmente la palabra "nombre". Pequeña diferencia. Cambia todo.

Unir textos: el signo +

En Python, los textos (strings) se pueden pegar usando el signo más:

saludo = "Hola" nombre = "Sofía" print(saludo + " " + nombre) # Resultado: Hola Sofía

Fíjate en el " " del medio: es un espacio en blanco metido entre comillas. Sin él, Python pegaría las palabras sin separación: HolaSofía. Los textos no traen espacios automáticos. Tú decides dónde van.

A esto se le llama concatenar. Suena pretencioso. Significa "pegar".

Listas: muchas cosas en una sola cajita

Hasta ahora cada variable guardaba una sola cosa. Pero a veces necesitas guardar varias. Para eso existen las listas. Se escriben con corchetes [ ] y los elementos separados por comas:

amigos = ["Vale", "Juan", "Ana"] print(amigos) # Resultado: ['Vale', 'Juan', 'Ana']

Para acceder a un elemento específico, usas su posición. Pero atención al detalle raro: Python empieza a contar desde 0, no desde 1. El primer elemento es la posición 0, el segundo es la 1, etc. (Por eso Sofía numeró así su lista del 0 al 4.)

print(amigos[0]) # Vale print(amigos[1]) # Juan print(amigos[2]) # Ana

Y para saber cuántos elementos tiene una lista, usas len() (de "length", longitud):

print(len(amigos)) # 3

El bucle for: hacer algo con cada elemento

Cuando tienes una lista y quieres hacer algo con cada elemento, usas for. Se lee así: "para cada cosa en la lista, haz esto".

frutas = ["manzana", "pera", "uva"] for fruta in frutas: print(fruta) # Resultado: # manzana # pera # uva

Tres detalles que siempre hay que respetar:

  • La línea del for termina con dos puntos :
  • Lo que va a hacer en cada vuelta se escribe indentado (con 4 espacios o un Tab al inicio)
  • El nombre fruta lo inventas tú: es una variable temporal que cambia en cada vuelta del bucle

La indentación (espacios al inicio) no es decorativa en Python. Es obligatoria. Es como Python sabe qué cosas pertenecen al bucle y cuáles no.

Decisiones: if y else

Las computadoras toman decisiones con if ("si") y else ("si no"). La estructura es:

edad = 17 if edad >= 18: print("Es mayor de edad") else: print("Es menor de edad") # Resultado: Es menor de edad

Para comparar cosas usas estos símbolos:

  • ==  es igual a (¡son dos signos! Uno solo es para asignar valor)
  • !=  es distinto de
  • >  mayor que   <  menor que
  • >= mayor o igual   <= menor o igual

Para combinar dos o más condiciones, usas and ("y"):

if edad >= 18 and edad <= 25: print("Tiene entre 18 y 25")

Veredicto · Cierre del caso

Encontraron a Sofía.

A las 16:42 del miércoles, ocho horas después de que tú resolvieras la última pista, la policía irrumpió en el segundo piso del edificio abandonado de la calle 72. Sofía estaba encerrada en una habitación interior, sin ventanas, con la boca tapada con cinta. Estaba viva. Asustada, deshidratada, pero viva.

Mateo Sánchez, 20 años, sin trabajo fijo, había estado siguiendo a Sofía durante tres semanas desde que la vio dibujando en el Parque Nacional. La obsesión escaló rápido. La noche del martes la abordó cuando salía del colegio. La amenazó. La llevó al edificio.

Pero Sofía, durante esas tres semanas, había hecho algo que ningún manual de autodefensa enseña: documentó todo en código. Cada vez que lo veía, abría su laptop esa misma noche y guardaba una variable nueva. Un nombre. Una hora. Un detalle físico. Nunca pensó que iba a usarlo así. Pensó que era solo una forma de practicar Python, su nueva obsesión.

«No fui valiente. Solo fui ordenada.»
— Sofía, en su declaración a la policía.

El caso se cerró en 36 horas.

Sin las pistas que tú resolviste — print, variables, concatenación, listas, bucles, condicionales — la policía hubiera tardado semanas. Tú las cruzaste en una tarde porque Sofía ya había hecho el trabajo difícil: dejar la información en un lenguaje que cualquiera dispuesto a aprender pudiera leer.

Eso es Python. Eso es programar. No magia, no genios encerrados. Solo personas ordenadas que aprendieron a pedirle al computador exactamente lo que necesitan.
